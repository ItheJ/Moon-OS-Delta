Moon OS Delta 1.3:
	* Упрощено использование команды pci
	* Теперь в mdver можно отслеживать uptime - рабочее время системы
	* Была добавлена команда ces - шифрует файл или введённое слово по Шифру Цезаря
	* Обновлена команда help
	* Добавлены параметры при запуске системы
	* Исправление некоторых ошибок при загрузке системы на реальном железе
	* Исправлена ошибка, из-за которой Moon OS Delta 1.3 не могла выйти

Moon OS Delta 1.2.2:
	* Новый ASCII арт при загрузке системы
	* Добавлена команда pci для чтения PCI шины
	* Добавлен детектинг AHCI контроллеров через pci --ahci
	* Финально исправлены и обновлены команды и драйвера, связанные с работой IDE
	* Повторно исправлен драйвер PC SPEAKER
	* Исправлена загрузка Moon OS Delta через grub (теперь не требует ручного запуска файла)
	* Добавлена новая команда rdhead - выводит первые n символов из файла
	* Добавлена новая команда rdtail - выводит последние n символов из файла
	* Добавлена новая команда chsymb - изменяет в файле все символы "a" на все символы "b"
	* Добавлена функция рандома в систему: в mdver и в MDcode (под номером 19, подробнее в файле DOCUMENTATION_MDCODE.txt)
	* Несколько десятков баг фиксов в ядре системы, при работе с файлами и в MDcode
	* В ядре заготовлены функции для работы с математикой...

Moon OS Delta 1.12:

	* Добавление редактора файлов MD READ & WRITE для большего удобства в чтении и записи в них.
	* Добавлены команды copyf и movf для копирования и перемещения данных файла.

	* Произошли небольшие баг фиксы в ядре и в MDcode.

Moon OS Delta 1.1:

	* Добавлены команды языка MDcode - 6-17 (подробнее об этом в файле DOCUMENTATION_MDCODE.txt)
	* добавлена команда timeset, которая устанавливает время и дату как через ручной ввод, так и через Unix timestamp
	* добавлена команда chdbg, которая включает и выключает Режим отладки в MDcode. Режим отладки представляет из себя выдачу данных буфера, адреса оператора и текущий оператор.
	* добалена работа с регистрами в MDcode - их 8, нужны для хранения данных.
	* вместе с MDcode 1.1 идут две программы на MDcode в форматах <команда записи в файл имя файла операция> и просто операциями - MDcalculate.mdxt и CtoF.mdxt .
	* произошли небольшие баг фиксы в ядре.
