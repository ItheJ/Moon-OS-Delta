Moon OS Delta 1.2.1:
	* Проведён полный рефакторинг системы!
	* Добавлена команда setcolor для изменения фона консоли
	* Добавлены 5 фонов консоли по умолчанию вместе с командой themes (Темы работают во всех частях Moon OS Delta) и доступны по нажатию клавиши F8
	* Обновлён экран "фатальной остановки ядра", получив косметические улучшения
	* Добавлена команда panic для вызова "фатальной остановки ядра". ИСПОЛЬЗОВАТЬ ТОЛЬКО ТОГДА, КОГДА ЗНАЕШЬ ТО, ЧТО ДЕЛАЕШЬ
	* Добавлена команда timer для засекания времени пользователем
	* Слегка обновился MDFS (RAM составляющая), ls и небольшие фиксы mdrw
	* Улучшена стабильность системы и проведены исправления ядра

Moon OS Delta 1.2:
	* Полностью переработан mdver - показывает больше и лучше информацию.
	* Были обновлены драйвера для PC Speaker - работает и на реальном железе!
	* Были добавлены новые обработчики исключений
	* Была улучшена стабильность системы и проведены баг фиксы.

Moon OS Delta 1.12:

	* Добавление редактора файлов MD READ & WRITE для большего удобства в чтении и записи в них.
	* Добавлены команды copyf и movf для копирования и перемещения данных файла.
	* Добавлен Moon OS Delta fatal stop для обработки разных исключений процессора
	* Переделана функция erase
	* Произошли небольшие баг фиксы в ядре и в MDcode.
	* Для Moon OS Delta была создана игра "Moon Delta PONG!".
	* Теперь стабильно запускается на реальном железе!

Moon OS Delta 1.1:

	* Добавлены команды языка MDcode - 6-17 (подробнее об этом в файле DOCUMENTATION_MDCODE.txt)
	* добавлена команда timeset, которая устанавливает время и дату как через ручной ввод, так и через Unix timestamp
	* добавлена команда chdbg, которая включает и выключает Режим отладки в MDcode. Режим отладки представляет из себя выдачу данных буфера, адреса оператора и текущий оператор.
	* добалена работа с регистрами в MDcode - их 8, нужны для хранения данных.
	* вместе с MDcode 1.1 идут две программы на MDcode в форматах <команда записи в файл имя файла операция> и просто операциями - MDcalculate.mdxt и CtoF.mdxt .
	* произошли небольшие баг фиксы в ядре.
